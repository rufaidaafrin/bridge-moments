# Bridge Moments

Bridge Moments is a static web prototype for an AI-assisted independence, transition, and speech/AAC support tool. It helps people use big text-and-visual cards to speak needs out loud, while caregivers can set up custom cards with photos, simple routines, sensory forecasts, plan-change rescue scripts, intent decoding for sounds/gestures/objects, adaptive pattern learning, easy-language translations, and a shareable support card.

Open `index.html` in a browser to run the project.

Open `feedback.html` to collect early user feedback. If deployed on Netlify, the form can be captured with Netlify Forms.

## Showcase description

Bridge Moments turns real-life stressful situations into simple, personalized support kits. It now includes My Mode, an independence-first screen with large visual cards, readable text, optional real photos, and one-tap speech for needs like help, water, bathroom, pain, quiet, or calling family. Caregivers can add custom cards that save in the browser. The app also learns locally from repeated taps and caregiver confirmations, such as when a sound plus an object often means water or when a certain card is used often in a specific context. These learned patterns update the My Voice Passport. The goal is to help people communicate and understand more on their own, while helping caregivers notice patterns they might otherwise miss.
