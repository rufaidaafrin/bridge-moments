# Bridge Moments

Bridge Moments is a static web prototype for an AI-assisted transition and speech/AAC support tool. It helps caregivers turn stressful or unfamiliar moments into simple visual previews, sensory forecasts, plan-change rescue scripts, speech phrase builders, intent decoding for sounds/gestures/objects, communication choices, easy-language translations, and a shareable support card for people with Down syndrome, autism, speech delays, or intellectual disabilities.

Open `index.html` in a browser to run the project.

## Showcase description

Bridge Moments turns real-life stressful situations into simple, personalized support kits. A caregiver can describe an upcoming moment, such as a dentist visit, school change, haircut, or loud public place, and the app creates a step-by-step preview with plain language, pictograms, a sensory forecast, a plan-change rescue script, a speech phrase builder, an intent decoder for unclear sounds, pointing, hand-leading, and objects, communication choices, an EasyWorld text translator, and a "My Voice Passport" support card. The goal is to reduce anxiety, support communication, and help families understand what someone may mean before frustration builds.
